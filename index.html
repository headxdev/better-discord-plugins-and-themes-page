📥 Installation

So installierst du die Themes und Plugins

1

BetterDiscord installieren

Lade BetterDiscord herunter und installiere es.

2

Theme herunterladen

Klicke auf "Download" beim Galaxy Theme oben oder lade es von GitHub.

3

Theme installieren

Kopiere die .theme.css Datei in den BetterDiscord Themes-Ordner:
%appdata%/BetterDiscord/themes

4

Theme aktivieren

Öffne Discord → Einstellungen → BetterDiscord → Themes → Galaxy Theme aktivieren

5

Galaxy Plugin (Optional)

Für den animierten Hintergrund: galaxyplugin.plugin.js in den Plugins-Ordner kopieren.
